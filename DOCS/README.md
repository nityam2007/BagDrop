## 💡 Quick Summary

**BagDrop** is a smart luggage storage and delivery platform that:

1. **Partners with local shops** near transit hubs for secure bag storage
2. **Offers contactless access** via OTP/NFC tokens
3. **Provides forgotten luggage delivery** anywhere in India
4. **Starts at ₹50 for 6 hours** — cheaper than railway cloakrooms
