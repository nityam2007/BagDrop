# BagDrop

**Smart Luggage Storage & Delivery Platform**

> *Secure. Contactless. Affordable.*

---

## About

BagDrop is a smart luggage storage and delivery network that partners with verified local shops, cafes, and hotels near transit hubs to provide secure bag storage for travelers. Our unique feature includes forgotten luggage delivery anywhere in India.

**Current Stage:** Ideation

---

## Problem We Solve

- Early hotel checkout but late departure
- Heavy bags ruining travel experience
- Overpriced/crowded railway cloakrooms
- No easy way to retrieve forgotten luggage

---

## Solution

1. **Find** - Locate nearby BagDrop storage via app
2. **Book** - Pay via UPI/Card/NFC
3. **Drop** - Store bags, get OTP/NFC token
4. **Retrieve** - Show token, collect bags
5. **Deliver** - Forgot bag? We courier it to you

**Starting at Rs.50 for 6 hours**
